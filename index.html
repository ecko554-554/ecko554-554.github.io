👋 What Is floorgazer?

floorgazer is a small, friendly desktop program for Windows that shows you the current floor price of NFT collections. A "floor price" is simply the lowest price someone is currently willing to sell a collectible from a specific collection for. It is the number most people look at first when they want to know how a collection is doing.

Instead of keeping a dozen browser tabs open, forgetting which one you were watching, and losing track of the market while you do something else, floorgazer puts those numbers into one tidy window on your own computer. You launch it, you glance at it, and you know what is happening.

The project is completely open source, which means the code is public and anyone can inspect it, learn from it, or help improve it. It is built as a native Windows application, so it feels like a normal program rather than a website pretending to be one. It is aimed at collectors, traders, and curious people who want simple market awareness without a complicated dashboard.

📊 Reading a Floor Price

The floor price is the cheapest listed item in a collection. If a collection has a floor of 10 and yesterday it was 12, the floor has dropped by 2. If it was 8 and is now 10, it has risen. That single number tells you which way the collection is leaning.

Floor price is not the whole story. A collection can have a high floor because only a couple of items are listed, while almost nobody is actually buying. Another collection might have a lower floor but steady sales all day. Treat the floor as a starting point for your own judgement, not as a final answer.

Comparing floors across collections is easiest when you watch them side by side over time. That is exactly what a tracker like floorgazer is for: not predicting the future, but giving you a clear picture of the present.

🛠️ If Something Goes Wrong

  • The download will not start. Check your internet connection and try again. Some networks block large downloads; if you are on a work or school network, try a different connection.
  • The file will not open. Make sure the download finished completely. A partial download cannot run. Delete it and download once more.
  • Windows blocks the app. This happens with new software. Open the prompt, confirm you trust the source (the official page linked above), and allow it to run.
  • Numbers look out of date. Use the refresh control in the app. Market data changes constantly, and a manual refresh is sometimes all you need.
  • Something else is odd. The project page has an issues area where you can describe the problem in plain language. You do not need technical vocabulary to report a bug.

🔒 Privacy and Safety

floorgazer is a viewer, not a wallet. It does not ask for your seed phrase, your private keys, or your login details, and you should never give those to any program. What it does is read publicly available information about collections and display it to you.

Because the source code is open, anyone with technical skills can read exactly what the program does. That kind of openness is one of the strongest trust signals a small utility can offer.

💡 Tips for New Users

  • Start with five collections, not fifty. A short list you actually check is more useful than a long one you ignore.
  • Look at the same time each day for a week. Trends become obvious when your observations are regular.
  • Keep a simple note of floors you find interesting. Memory is unreliable, and a written number is not.
  • Remember that floor price moves for boring reasons too: someone listing one item cheaply can shift it for a few minutes. Give it time before drawing conclusions.
